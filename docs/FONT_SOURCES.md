# Font assets

The interface loads the supplied City family as its primary typeface and binds all headings directly to the supplied Babylon 5 font file.

| File | Source supplied with the project | Use |
| --- | --- | --- |
| `public/fonts/city-regular.ttf` | City Regular archive | Body and interface text |
| `public/fonts/city-medium.ttf` | City Medium archive | Medium and bold interface text |
| `public/fonts/B5______.ttf` | User-supplied `B5______.ttf` (also present in `babylon5.zip`) | All page headings |

The font archives do not include clear web embedding or redistribution grants. The City Regular readme identifies the typeface as a copyrighted program; the City Medium font metadata identifies Adobe/Berthold copyright and trademark claims. The Babylon 5 archive contains only generic installation notes. These files are included here because they were supplied for this personal prototype. Confirm suitable web use rights or replace the fonts before making the application publicly available.
